Both products can be considered when inspecting or reducing model-context
overhead. LeanCTX's available local Runtime primitives are designed to be used
with an existing coding agent and must be assessed on the actual workload.

## Evidence boundary

A lower token or calculated-cost figure alone is not a win. A valid comparison
uses a comparable baseline and treatment, a declared quality threshold, the
cost basis, and inspectable methodology. Earlier competitive claims and figures
are historical and are intentionally not reproduced here.

LeanCTX is **The Context SDK for AI Agents**; it is not a hosted cost-management
or analytics platform. See the internal
Product Architecture (`docs/internal/vision/PRODUCT-ARCHITECTURE.md`, internal — not in this repository).
