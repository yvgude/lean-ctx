# LeanCTX channel copy

Approved copy for repository, package and directory entry points.
LeanCTX is the **Context Gateway for AI Systems**. **Control what your AI can see.**
Product scope follows [canonical positioning](../POSITIONING_CANONICAL.md).

## Shared description

LeanCTX helps AI tools select relevant context, apply supported controls, retain
local knowledge and inspect recorded evidence. Select · Control · Learn · Prove.
Your application, agent loop and model stay yours.

Controls apply to supported paths and configured detectors. Learn means local
context continuity. Evidence covers observed operations; context-only receipts
do not prove the host's later model call. Do not add savings percentages.
