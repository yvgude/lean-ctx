# Telemetry LIA checklist

- [ ] purpose and necessity documented
- [ ] lawful basis and user notice approved
- [ ] allowlisted fields reviewed; content and secrets excluded
- [ ] opt-out, deletion, retention, and access workflows tested
- [ ] processor, transfer, and residency terms reviewed
- [ ] DPIA/LIA owner and review date recorded

This checklist is an implementation gate, not legal approval.
