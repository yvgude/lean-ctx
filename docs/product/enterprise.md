# LeanCTX Enterprise

Enterprise adds governance and deployment control: SSO/SCIM, RBAC, identity,
policy, provider and data classification, residency, budgets, retention,
auditing, VPC/on-premise and air-gapped operation. These controls apply before
data transfer and execution and produce inspectable audit records.

Enterprise does not remove the public safety bounds or require proprietary
code for local fallback. Commercial terms, support, and deployment artifacts
are governed by a separate Thinkery AG agreement.
